# Courses Section - Internexis Technologies

This directory contains the complete courses section for the Internexis Technologies website, featuring premium courses at ₹399 each.

## 🎯 Overview

The courses section includes:
- **Landing Page** (`/courses`) - Grid layout showcasing all available courses
- **Individual Course Pages** - Detailed course information with curriculum, projects, and features
- **Responsive Design** - Mobile-friendly layout with Tailwind CSS
- **Interactive Elements** - Framer Motion animations and hover effects
